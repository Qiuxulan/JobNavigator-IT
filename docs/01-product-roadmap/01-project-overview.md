# 项目概览（产品视角）

## 1. 问题定义

本项目针对 IT 求职中的四个核心痛点：

1. 方向难选：热门岗位多，但个人是否可达不清晰
2. 差距不清：知道不够，但不知道缺什么、先补什么
3. 过程割裂：推荐、学习、投递、趋势没有打通
4. 风险不明：缺少岗位竞争、波动、替代风险的量化提示

## 2. 产品定位

提供“可解释职业决策”而非单点工具，输出包括：

1. 岗位推荐卡（含分数与理由）
2. 技能缺口分析
3. 学习路径与资源建议
4. 趋势与风险提示

## 3. 用户分层

1. 新手：需要方向和路径
2. 求职者：需要匹配和提升计划
3. 进阶从业者：需要趋势判断和转向评估

## 4. V1 非目标

1. 不做完整 Agent 编排
2. 不覆盖非 IT 行业
3. 不做复杂多租户权限系统
