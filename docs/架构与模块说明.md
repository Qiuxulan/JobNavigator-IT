# JobNavigator-IT 架构与模块说明

本文合并了原 `reports/model_chain.md`、`reports/summary/*`、`reports/trend/*` 中仍然有效的内容，描述当前（2026-11）系统的真实链路。课程阶段已下线的方案（PatchTST 岗位预测、GDELT 事件特征、GraphSAGE 精排、JobBERT 召回）不再出现在主链路中。

## 1. 总体结构

```
数据采集层 ──────────────────────────────────────────────────────────────
  国内官网岗位（每日）  49 家官网 + 国聘（央企国企）+ 公共招聘网（中小企业），聚合平台含薪资字段   pipelines/cn_jobs/collect.py
  全球 JD 样本（每月）  8 个公开数据源融合，12.99 万条（海外为主）        pipelines/extract/unify_jd_v3.py
  行业新闻（每 3 小时） 14 个中英文来源                                pipelines/news/collect.py
  海外参考信号（每月）  海外公司在招、HN 招聘帖、美国 WARN 裁员          pipelines/trend/*
          │
处理层 ──────────────────────────────────────────────────────────────────
  技能抽取：skill_vocab_v2/v4 中英文词典匹配（国内 JD 另加中文同义词）
  岗位归类：99 个细粒度岗位（国内 JD 用中文岗位名规则映射）
  国内市场：在招数 / 公司 / 城市 / 技能 / 经验 / 每日新增与下架      pipelines/cn_jobs/build_market.py
  岗位画像、技能先修图、学习资源库、技能趋势面板                      pipelines/taxonomy, graph, report, trend
          │
模型层 ──────────────────────────────────────────────────────────────────
  Qwen3-Embedding-4B 语义召回（pgvector） │ LightGBM LambdaRank 排序 │ 分数校准
  技能先修 DAG + 拓扑约束路径规划 │ Chronos-Bolt / damped Holt 技能占比预测（海外样本）
  DeepSeek Agent（工具调用全部落在本地数据）
          │
服务层（FastAPI，app/） ─────────────────────────────────────────────────
  /v1/market/*  国内市场 │ /v1/jobs/recommend 岗位匹配 │ /v1/paths/generate 学习路径
  /v1/graph 知识图谱 │ /v1/news 新闻 │ /v1/agent/chat AI 助手 │ /v1/me/* 个人中心
          │
前端 ────────────────────────────────────────────────────────────────────
  网页 frontend/（React + Vite）  │  微信小程序 miniprogram/（Taro 4）
```

## 3. 关键方法

### 3.1 国内实时数据（2026-11 新增）
- **采集**：各公司官网公开的岗位列表接口，单线程、请求间隔 0.4 秒；每天一次全量快照。
- **过滤**：岗位名/职能类别命中研发、算法、测试、运维、数据、安全、产品等关键词保留；销售、运营、门店、市场等剔除；海外城市剔除。
- **进出记录**：`jobs_ledger.jsonl.gz` 记录每个岗位的首次出现/最后出现日期，由此得到每天的在招数、新增数、下架数——这是国内真实的时间序列，随采集天数自然增长。
- **技能抽取**：词典匹配，技能覆盖率 78.1%（含聚合平台口径，中小企业 JD 描述较短拉低了比例）。
- **岗位归类**：60 余条中文岗位名规则，72.6% 的岗位归到具体细分岗位（含两个聚合平台口径，中小企业岗位名更多样），其余归“通用软件工程师”。

### 3.2 岗位匹配
- 公式分 `0.15×技能覆盖 + 0.70×语义 + 0.15×趋势`（58 例网格调参）。
- 线上默认 LTR：LightGBM LambdaRank，用 DeepSeek 精排结果蒸馏（2500 条教师标签，21 维本地特征）。58 例评估 Hit@1 1.0、NDCG@5 0.774（`reports/eval/ltr_eval.json`）。
- 校准：p5/p95 锚点分段线性，展示分区分度提升约 2.9 倍；排序仍用原始分，保证单调。

### 3.3 学习路径
- 先修 DAG：LLM 三路独立构建 + 投票融合 + 环检测。
- 规划：拓扑约束下综合难度匹配（最近发展区）、资源覆盖、学时惩罚、可迁移技能折算。
- 个性化一致性 τ 从旧版 0.001 提升到 0.343（`reports/eval/path_v4_eval.json`）。

### 3.4 趋势（海外参考）
- 全球技能月度占比面板 630 技能 × 37 月；Chronos-Bolt 与 damped Holt / naive 逐技能交叉验证选模，中位 MAPE 0.307 vs 0.373（`reports/eval/chronos_vs_holt_eval.json`）。
- **口径问题**：全球样本各月份的数据源构成变化很大（2026-07 有 3.6 万条，2026-08 只有 2700 条），占比跳变多来自换源而非真实需求变化。因此：上升/衰退榜加了“基期样本 ≥30、月样本 ≥1000”的门槛，且三张榜互不重复；页面只把它作为“海外参考”，国内判断以官网实时数据为准。
