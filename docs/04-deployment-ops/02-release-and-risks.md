# 发布与风险管理

## 1. 发布前检查清单

1. `pytest -q` 全通过
2. `docker compose config` 解析通过
3. `/v1/health` 返回 200
4. 主链路接口可调用（extract/recommend/path/trend）

## 2. 当前主要风险

1. 外网受限导致镜像或依赖拉取失败
2. 数据源时效波动导致推荐质量波动
3. 弱监督噪声影响抽取模型质量
4. 旧文件权限锁导致清理困难

## 3. 风险应对

1. 依赖与镜像镜像源预案
2. 数据质量标签 + 抽样巡检
3. 小规模金标持续校正
4. 文档与接口版本冻结机制

## 4. 回滚策略

1. 代码回滚：回退到稳定 tag
2. 数据回滚：恢复数据库备份
3. 服务回滚：恢复上一版 compose
