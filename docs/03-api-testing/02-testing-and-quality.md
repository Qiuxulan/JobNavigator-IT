# 测试与质量策略

## 1. 测试分层

## 1.1 单元测试（`tests/unit`）

覆盖：

1. 抽取服务逻辑
2. 推荐打分逻辑
3. 路径生成逻辑
4. 趋势输出逻辑

## 1.2 集成测试（`tests/integration`）

覆盖：

1. API 健康检查
2. 抽取 -> 推荐主链路
3. 路径、趋势接口
4. 预留接口返回码一致性

## 2. 指标体系

## 2.1 抽取层

1. 实体级 F1（技能/岗位/学历/薪资）
2. 标准化准确率
3. OOV 新技能召回率

## 2.2 推荐层

1. TopK 命中率
2. NDCG@5
3. 硬约束违规率（学历/薪资/城市）

## 2.3 路径层

1. 先修关系冲突率
2. 路径可执行性评分
3. 人工评审通过率

## 2.4 趋势层

1. 方向准确率（升/平/降）
2. 证据覆盖率

## 3. 工程质量门禁

1. `pytest` 必须通过
2. 关键 API 契约测试必须通过
3. Docker 配置可解析（`docker compose config`）
