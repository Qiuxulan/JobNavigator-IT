# 数据与更新机制

## 数据来源

| 数据 | 口径 | 更新 | 产物 |
|---|---|---|---|
| 国内在招岗位 | 51 个源：49 家公司官网社招页公开接口（6 大厂 + 阿里系 15 站点 + 飞书托管 28 家）+ 两个聚合平台——国聘（央企国企，含月薪/学历/完整 JD）、中国公共招聘网 mohrss（人社部平台，覆盖全国中小企业，含月薪/发布日期），只保留 IT 岗、国内城市 | 每天 | `data/cn_jobs/`（快照、进出记录），`data/gold/cn_market_v1.json` |
| 全球 JD 样本 | 8 个公开数据集融合，12.99 万条，2023-10 ~ 2026-10，国内占比 < 1% | 每月 | 主数据在 `/data/shichaojian/JNIT/processed/jd_unified_v4_enriched/`；画像 `data/gold/role_profiles_v3.json`；面板 `skill_trend_panel_v3.json` |
| 行业新闻 | 14 个中英文来源 | 每 3 小时 | PostgreSQL `news_items` |
| 海外参考信号 | 海外 25 家公司在招（ATS）、HN Who is Hiring、美国 WARN 裁员 | 每月 | `company_hiring_momentum.json`、`layoff_signals.json` |
| 学习资源 | Coursera/B 站/GitHub 等 2006 条，162 门含章节 | 手动 | `learning_resources_v5.json` |

国内薪资：官网不公开薪资的部分不展示、不编造；国聘与中国公共招聘网岗位自带月薪上下限，如实展示并标注来源；页面上的美元薪资均标注“海外参考”。

## 定时任务

| 任务 | 频率 | 命令 | 配置 |
|---|---|---|---|
| 国内岗位采集 + 市场聚合 | 每天 07:30 | `python -m pipelines.cn_jobs.collect && python -m pipelines.cn_jobs.build_market` | `infra/cron/jobnav-cnjobs`（需安装到 `/etc/cron.d/`） |
| 新闻采集 | 每 3 小时 | `python -m pipelines.news.collect --hours 48` | `/etc/cron.d/jobnav-news` |
| 全球数据月度更新 | 每月 3 日 | `python -m pipelines.monthly_update` | `/etc/cron.d/jobnav-monthly` |

后端读取数据文件时按修改时间自动刷新缓存，产物更新后无需重启服务。

## 常用命令

```bash
python -m pipelines.cn_jobs.collect                     # 采集国内官网岗位（需外网代理）
python -m pipelines.cn_jobs.build_market                # 生成 data/gold/cn_market_v1.json
bash scripts/start_api.sh                               # 重启后端（读取 .env，日志 /tmp/jobnav_api.log）
cd frontend && npm run build                            # 网页端构建
cd miniprogram && npm run build:weapp                   # 小程序构建
python -m pytest -q                                     # 测试
```

## 新增一家公司

在 `pipelines/cn_jobs/collect.py` 中写一个 `fetch_xxx(session, max_pages)` 生成器，返回 `record(...)` 构造的统一字段，并在 `COMPANIES` 与 `FETCHERS` 中登记即可；过滤、进出记录、聚合逻辑无需修改。
