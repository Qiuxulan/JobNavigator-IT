# 迁移与上线指南

> 回答两个问题：①云平台环境到期后迁移到自己电脑难不难（本地无显卡）；②网页/小程序真正上线要走的流程和费用。
> 结论先行：**迁移不难**（要拷的东西总共约 250MB + 数据库导出 + 可选的模型文件）；**上线总成本第一年约 200~1500 元**，小程序个人主体可以零认证费上线（功能略受限）。

---

## 一、迁移到本地（无 GPU）可行性

### 1. 哪些东西不在 GitHub 上（需要手动拷走）

| 内容 | 大小 | 迁移方式 | 说明 |
|---|---|---|---|
| `data/gold/` 全部运行时产物 | **36MB** | scp/rsync/U盘 直接拷 | 市场、画像、趋势面板、校准参数、先修图、资源表，全部在此 |
| `data/cn_jobs/` 台账与快照 | 97MB（台账本身 6MB） | 拷台账即可，快照可选 | 时间序列的历史全在里面 |
| `models/ltr_ranker_v1.*` | 1.4MB | 直接拷 | LTR 排序模型 |
| PostgreSQL 数据库 | 新闻 2.3 万条 + 99 岗位向量 + 用户数据 | `pg_dump` 导出再恢复 | 约几百 MB |
| HuggingFace 模型缓存 | Qwen3-Embedding-4B 7.6GB + Chronos 183MB | 能联网就重新下载（`huggingface-cli download`），不能就连缓存目录一起拷 | 这是唯一的大件 |
| `/data/shichaojian/JNIT/` 原始数据集 | 2.4GB | **可以不拷** | 只在"重新跑月度流水线重建产物"时才需要；拷了产物就不需要它。想保留重跑能力再拷 |

**总计：必拷约 250MB + 数据库导出 + 模型 7.8GB（可重新下载）。半天之内能完成，不存在硬困难。**

### 2. 当前实时在跑的东西有哪些（迁移后要不要常驻后台）

| 程序 | 作用 | 迁移后是否需要 |
|---|---|---|
| uvicorn 后端（:8000） | 所有 API | **要**，网页/小程序访问就得开着（笔记本开着就跑，关机即停） |
| vite preview（:5173） | 网页前端 | 同上；也可以 `npm run build` 后把静态文件交给后端/任意静态服务器 |
| tailscaled + Funnel | 小程序公网访问后端 | 本地迁移后**不再需要**——上线时换自己的域名，demo 阶段也可以继续用它 |
| cron：国内岗位采集（每天 07:30） | 每日采集 + 重建市场数据 | 想保持"实时"就需要一个每天开机的机器；笔记本可以配 crontab/Task Scheduler，关机就跳过当天 |
| cron：新闻采集（每 3 小时） | 新闻更新 | 同上 |
| cron：月度链路（每月 3 号） | 全球数据 + 模型重建 | 可选，不跑只是数据停更，系统照常可用 |

**模型不需要每天重跑**：每日链路只做"采集 → 过滤 → 聚合"（纯 CPU、几分钟）；模型类任务（LTR 重训、Chronos 重选模、向量重建）都在每月链路里，且是可选的。

### 3. 没有显卡能不能跑（关键问题）

**能。推理端全部可以 CPU：**

| 模型 | GPU 需求 | 无显卡表现 |
|---|---|---|
| Qwen3-Embedding-4B（用户画像编码，每次匹配 1 次） | 无硬性需求 | 约 8GB 内存，CPU 单次编码 2~5 秒，演示/低频使用可接受 |
| Chronos-Bolt-small（趋势预测，183M 参数） | 无 | CPU 完全够用（实测 GPU 峰值显存也才 106MB） |
| LightGBM LTR（排序） | 无 | 微秒级 |
| GraphSAGE（可迁移技能相似度） | 无 | 推理是查向量，CPU 秒回 |
| DeepSeek（助手/审核） | 不需要本地算力 | 走 API，按 token 付费 |

**优化选项（可选）**：把向量模型换成 Qwen3-Embedding-0.6B（小 7 倍），重新编码 99 个岗位向量只要几分钟，CPU 单次编码降到 1 秒内——这个替换我可以帮你做。
**不建议在本地跑的事**：月度链路里的全量重建（12.99 万 JD 重新抽技能、逐技能 Chronos 回测）在 CPU 上要几小时到一天，可以仍在云上跑完再把产物拷回来，或者接受本地跑慢点。

## 二、网页上线（域名 + 备案 + 服务器）

| 项目 | 费用（2026 年行情） | 说明 |
|---|---|---|
| 域名 .com | **首年 90 元，续费 99 元/年**（[阿里云 2026-11 调价](https://m.sohu.com/a/1091452247_121885030)） | .cn 更便宜（约 29~39 元首年）；冷门后缀（.top/.xyz）首年几块钱但不推荐正式用 |
| ICP 备案 | **免费** | 域名指向大陆服务器就必须备案，在服务器厂商后台提交，约 1~3 周，需要身份证 + 人脸核验 |
| 服务器 | 学生机/轻量应用服务器促销约 **60~100 元/年**，常规约 50~80 元/月 | 本项目 2 核 4G 足够（CPU 推理 4B 向量模型建议 4 核 8G） |
| HTTPS 证书 | **免费**（Let's Encrypt 或云厂商免费证书） | 小程序后端强制 HTTPS |
| **合计（第一年）** | **约 200~1200 元** | 学生优惠渠道最便宜 |

## 三、小程序上线（流程 + 费用）

你已经有个人主体 AppID（wx632a3e490ab0efe5），距离上线还差：

1. **小程序备案（免费，必须）**：2023 年 9 月起工信部要求小程序也要 ICP 备案。在 mp.weixin.qq.com「设置 → 小程序备案」提交，身份证 + 人脸核验，约 3~20 个工作日。**不备案不能发布**。
2. **类目选择**：选"工具 → 信息查询"或"教育 → 教育信息服务"类，我们这类职业规划工具一般不需要特殊资质。
3. **服务器域名配置（必须）**：小程序后台「开发管理 → 服务器域名」把后端 API 域名加入 request 合法域名，要求 **HTTPS + 已 ICP 备案的域名**——所以网页域名备案搞定后小程序复用同一个域名即可（如 api.你的域名.com）。
4. **上传 → 提审 → 发布**：开发者工具上传，mp 后台提交审核，[审核普遍 1~3 天](https://kuku.baidu.com/landing/tscp_doc/c1423f13836e9ef21ef07ce71f7752bf)，通过后点发布。
5. **费用**：
   - **个人主体：0 元**（免认证费），但功能受限——不能用 web-view 内嵌外链（我们新闻页已经是"复制链接"方案，不受影响）、部分经营类目不可选、不能用微信支付
   - **企业/个体户主体：认证费 300 元/年**（[微信官方](https://developers.weixin.qq.com/miniprogram/introduction/)），可解锁 web-view 业务域名、微信支付、更多类目；2026 年部分渠道显示个体户有 30 元/次档位
   - 后端托管替代方案：**微信云托管/云开发**，免自己买服务器和备案 API 域名，按量计费，低流量每月几块钱，是个人主体最省事的后端方案

**推荐路线（总预算最小）**：个人主体小程序（0 元）+ 云托管后端（几元/月）；如果之后要 web-view 和企业能力，再花 300 元/年做企业认证。网页版是否独立上线看需求——小程序内已经覆盖核心功能，网页可以作为 PC 端补充挂在同一个域名下。

## 四、时间线建议

1. 云平台到期前：拷产物（250MB）+ `pg_dump` 数据库 + 模型缓存（或记录重新下载命令）
2. 买域名 + 轻量服务器，提交 ICP 备案（1~3 周，期间可以在本地跑通）
3. 本地/新服务器恢复数据库、起后端前端，验证网页
4. 小程序备案（与 ICP 并行）→ 配置 API 域名 → 提审 → 发布
