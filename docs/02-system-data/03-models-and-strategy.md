# 模型与策略（重点解答模型问题）

## 1. 抽取模型设计

## 1.1 为什么要双通道

1. JD 中部分字段是结构化字段，可直接抽取
2. 简历/GitHub 是非结构化文本，必须用文本抽取模型

## 1.2 标签体系（统一训练目标）

1. 技能（Skill）
2. 岗位（Role）
3. 学历（Education）
4. 年限（Experience）
5. 薪资（Salary）
6. 城市（City）
7. 项目证据（ProjectEvidence）

## 1.3 标注数据不足时的方案

针对你提出的“旧数据集技能老化、字段不全”问题：

1. 旧公开标注集作为初始监督
2. 规则 + 模板 + LLM 自标注生成银标
3. 人工抽样校验形成高质量小金标
4. 每周执行新技能增量词表更新

## 1.4 训练路线

1. 阶段一：规则+弱监督可用版本
2. 阶段二：LoRA/QLoRA 微调抽取模型

## 2. 推荐模型设计（双阶段）

## 2.1 召回层（性能优先）

使用 pgvector ANN 做 TopN 岗位候选，避免“用户样本对全库暴力匹配”。

## 2.2 精排层（质量优先）

融合四类信号：

1. 语义相似分
2. 硬约束分（学历/薪资/城市）
3. 路径代价分（转型难度）
4. 趋势奖励分（长期成长性）

输出可解释分解，不只给总分。

## 3. 学习路径生成策略

## 3.1 先修顺序来源

1. 课程大纲与教程目录抽取
2. 技能关系规则库
3. 人工抽样修正

## 3.2 生成流程

1. 识别缺口技能
2. 在 `PREREQ` 子图排序
3. 生成多候选路径
4. 路径打分并选 Top 路径
5. 逐步挂载资源

## 4. 趋势模型策略

1. 先用稳态基线（ARIMA/线性），确保可落地
2. 结合事件证据做解释
3. 后续升级多变量/深度时序模型
