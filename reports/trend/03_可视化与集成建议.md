## 3. 知识图谱集成

### 3.1 现有图谱基础

项目中已有 `/pipelines/graph/` 下的知识图谱构建代码，包含：
- 角色-技能关系（JOB_REQUIRES）
- 技能前置关系（SKILL_PREREQ）
- 技能-学习资源关系（SKILL_HAS_RESOURCE）

### 3.2 建议集成方式

#### 方案 A：将趋势数据叠加到图谱上

在现有角色节点上叠加趋势信息：

```
                    ┌──────────┐
                    │  Python  │
                    └────┬─────┘
                         │ SKILL_PREREQ
                    ┌────▼─────┐
                    │ PyTorch  │
                    └────┬─────┘
                         │ JOB_REQUIRES
              ┌──────────▼──────────┐
              │   AI Engineer       │
              │  趋势: ↗ 0.72      │  ← 叠加趋势数据
              │  置信度: 85%       │
              └──────────┬──────────┘
                         │ JOB_REQUIRES
              ┌──────────▼──────────┐
              │   RAG Engineer      │
              │  趋势: ↗ 0.68      │  ← 叠加趋势数据
              └─────────────────────┘
```

#### 方案 B：趋势图谱专用视图

构建一个专门展示趋势关系的图谱：
- 节点 = 角色（按趋势方向着色：绿=上升，红=下降，灰=平稳）
- 边 = 角色间相似度（基于 shared_skills 计算）
- 点击节点 → 展开详情

#### 方案 C：时序图谱动画

将时间维度加入图谱：
- 每个时间点生成一张图谱快照
- 按时间顺序播放，展示趋势演变
- 节点大小 = 当前需求指数
- 节点颜色 = 趋势方向

### 3.3 图谱可视化工具建议

| 工具 | 优势 | 劣势 |
|:----|:----|:-----|
| **D3.js** | 高度可定制，Web 原生 | 学习曲线陡峭 |
|---|---|---|
| **Cytoscape.js** | 图论专用，上手快 | 定制化有限 |
|---|---|---|
| **Vis.js** | 简单易用，文档好 | 性能一般 |
|---|---|---|
| **ECharts** | 国内流行，关系图支持 | 复杂图谱吃力 |
|---|---|---|
| **Neo4j + Bloom** | 企业级图数据库 | 部署重 |
|---|---|---|

**建议**：前端用 **ECharts** 或 **Cytoscape.js** 快速出效果，后续可迁移到 D3.js 做深度定制。

## 4. Agent 系统集成

### 4.1 整体架构

```
用户输入 (自然语言)
    │
    ▼
┌──────────────────────────────────────┐
│           LLM (GPT-4 / Claude)       │
│                                      │
│  System Prompt:                      │
│  - 你是行业趋势分析助手                │
│  - 可使用以下工具:                    │
│    1. query_trend(role) → 趋势预测    │
│    2. retrieve_evidence(role, time)   │
│    3. get_role_list() → 所有角色      │
│    4. compare_roles(roles) → 对比     │
└──────────────┬───────────────────────┘
               │
    ┌──────────┴──────────┐
    │  工具调用层          │
    │  (function calling) │
    └──────────┬──────────┘
               │
    ┌──────────▼──────────┐
    │  后端 API 服务       │
    │  (FastAPI / Flask)  │
    └─────────────────────┘
```

### 4.2 建议的 Agent 能力

#### 能力 1：简历解析 + 用户画像
- 输入：简历文本
- 输出：技能列表、经验年限、目标岗位、教育背景
- 后端：调用 `ExtractorService`

#### 能力 2：职业路径规划
- 输入：用户画像
- 输出：技能差距分析、学习路径（含资源链接）、预计学习时长
- 后端：调用 `CareerPathwayService` + `PathPlannerService`

#### 能力 3：岗位推荐
- 输入：用户画像
- 输出：匹配岗位列表（含匹配分）
- 后端：调用 `RecommenderService`

#### 能力 4：趋势查询
- 输入：角色名（或分类名）
- 输出：趋势方向、置信度、历史数据、预测值
- 后端：调用组员 1 的接口

#### 能力 5：证据检索
- 输入：角色名 + 时间范围
- 输出：相关新闻事件 + JD 链接
- 后端：调用组员 2 的接口

#### 能力 6：多角色对比
- 输入：多个角色名
- 输出：对比表格 + 雷达图
- 后端：批量调用趋势 + 证据

#### 能力 7：报告生成
- 输入：角色名 + 时间范围
- 输出：Markdown 格式的完整分析报告
- 包含：用户画像 → 路径 → 推荐 → 趋势 → 证据

## 5. 整体集成方案

### 5.1 技术栈推荐

| 层次 | 推荐技术 | 备选 |
|:----|:--------|:----|
| **前端框架** | React + TypeScript | Vue 3 + TypeScript |
|---|---|---|
| **UI 组件库** | Ant Design Pro | Element Plus |
|---|---|---|
| **图表库** | ECharts + D3.js | Chart.js / Recharts |
|---|---|---|
| **图谱** | Cytoscape.js | Vis.js / D3.js |
|---|---|---|
| **后端** | FastAPI (Python) | Flask |
|---|---|---|
| **Agent 框架** | LangChain | AutoGen / 直接 API |
|---|---|---|
| **LLM** | GPT-4o / Claude 3.5 | 本地 Qwen / DeepSeek |
|---|---|---|
| **向量数据库** | ChromaDB (轻量) | FAISS / Qdrant |
|---|---|---|
| **部署** | Docker + Nginx | Vercel (前端) |
|---|---|---|

### 5.2 推荐开发路线

```
第 1-2 周：后端 API 开发
  ├── FastAPI 服务搭建
  ├── 趋势查询接口（对接组员 1）
  ├── 证据检索接口（对接组员 2）
  └── 角色列表接口

第 3-4 周：前端基础页面
  ├── 仪表盘首页
  ├── 角色详情页
  ├── 趋势对比页
  └── API 对接

第 5-6 周：Agent + 图谱集成
  ├── LangChain Agent 搭建
  ├── Agent 工具注册
  ├── 知识图谱页面
  └── AI 对话页面

第 7-8 周：联调 + 优化
  ├── 全链路联调
  ├── UI 打磨
  ├── 性能优化
  └── 文档编写
```

### 5.3 部署方案

**轻量方案（推荐 MVP）**：
```
前端: Vercel / GitHub Pages 部署静态页面
后端: 一台服务器 / 本地运行 FastAPI
数据库: 本地文件 + ChromaDB（无需独立数据库）
Agent: 直接调用 OpenAI API
```

**正式方案**：
```
前端: Nginx + Docker
后端: Docker Compose (FastAPI + Redis + Celery)
数据库: PostgreSQL + ChromaDB
图谱: Neo4j（可选）
Agent: LangServe 部署
```

### 5.4 大文件处理建议

两个大文件（2.66GB + 170MB）不适合放在 Git 中：

- **开发环境**：从网盘下载到本地 `data/gold/` 目录
- **生产环境**：放在 NAS 或对象存储（OSS/S3），后端按需加载
- **样本数据**：提供一份小样本（`*_sample.json`），方便前端开发调试

## 6. 最终交付效果示例

### 6.1 用户旅程

```
用户第一次使用
    │
    ▼
输入简历 / 描述技能
    │
    ▼
Agent 分析 → 展示用户画像
    │
    ├── 技能雷达图
    ├── 经验时间线
    └── 目标岗位识别
    │
    ▼
Agent 推荐 → 职业路径
    │
    ├── 技能差距列表
    ├── 学习路径（含资源）
    └── 预计学习时长
    │
    ▼
Agent 预测 → 趋势分析
    │
    ├── 目标角色趋势折线图
    ├── 多源对比（JD/新闻/GitHub）
    └── 关键证据链接
    │
    ▼
用户继续追问「为什么这个角色在上升？」
    │
    ▼
Agent 调证据接口 → 返回新闻事件列表
    │
    ▼
用户满意 → 生成完整报告

### 6.2 核心亮点

1. **数据驱动**：所有分析基于真实招聘数据和新闻数据，非凭空猜测
2. **可回溯**：每个预测结论都有历史数据支撑，可查可证
3. **有证据**：每条趋势分析都附带新闻事件和 JD 链接作为证据
4. **可交互**：用户可以通过自然语言与 Agent 对话，获取定制分析
5. **可视化**：趋势、对比、图谱等直观展示，降低理解门槛
```
