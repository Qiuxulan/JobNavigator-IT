选题背景

AI与新兴技术引发岗位结构性变迁
- 2025年我国数字经济核心产业增加值达14.0891万亿元，占GDP的10.5%。
- 全球劳动力市场也经历着岗位新生与替代并行的结构性重组。
- 2025年1—10月中国AI新发布岗位同比增长543%，9月单月增幅超过11倍。
- 高性能计算工程师人才供需比仅0.31。
- “岗位增长快、人才供给慢”的结构性紧缺现象。

职业世界：在AI、数字经济和平台化就业共同作用下，转向“岗位快速重组、技能持续迭代、求职全过程智能化”的动态模式。

技能更新与职业竞争格局加速
- 预计到2030年，约39%的关键岗位技能将发生变革；岗位所需技能中约70%面临更新压力。
- 自2022年以来职场人新增技能的速度提升140%。

就业市场整体压力及结构性困境
- 中国城镇青年（16—24岁）失业率长期在高位波动，青年失业率持续显著高于整体水平，部分月份超过16%以上，远高于平均约5%的总体失业率水平。

第5页｜用户痛点
============================================================
用户痛点

01 职业方向难抉择
- 行业快速增长，但个人能否顺利进入存在极大不确定性。
- 不同岗位对专业背景、项目经验和技能栈要求差异大，容易在热门赛道中盲目跟风。

02 能力差距不清晰
- 岗位技能快速迭代且描述不统一。
- 求职者虽知道自己能力还不够，却难判断缺的是基础能力、工具技能、项目经验，还是跨岗位迁移能力，也不清楚补齐顺序。

03 求职流程碎片化
- 从招聘平台到简历工具、面试系统、测评产品、刷题社区，信息和功能繁多。
- 但“岗位推荐—能力诊断—学习路线—投递准备”没有串联，用户需自行拼接流程。

04 缺乏风险与长期价值分析
- 现有工具通常只告诉用户“能不能投”，但难评估岗位竞争强度、波动趋势、技术替代风险及中长期成长性，无法帮助用户进行理性决策。

当代求职者：在高速变化的行业生态中判断方向、识别能力缺口，并把职业选择转化为可执行的学习与迁移路径。

第6页｜市场分析与现有技术缺陷
============================================================
市场分析与现有技术缺陷

市场产品
1. 综合招聘平台（LinkedIn、智联招聘）
- 主要解决岗位获取与匹配效率。
- 但缺乏对个人能力缺口、职业路径和行业趋势的解释性输出。

2. AI求职辅助工具（Jobscan、EasyResume）
- 聚焦简历优化或面试辅助。
- 未能形成跨阶段的职业成长路线与学习规划。

3. 测评/备考平台（BOSS直聘测评）
- 偏向应试和短期准备。
- 无法支撑长期跨岗位迁移或行业风险分析。

现有技术
1. 岗位文本理解系统（DeepCompJob、SkillParser）
- 侧重技能抽取、岗位结构化。
- 但缺乏个人画像和闭环决策支持。

2. 职业路径预测系统（CareerBERT）
- 能预测下一步岗位。
- 但依赖大量私有轨迹数据，公开实验规模有限，缺乏技能补全和学习路径。

3. 行业预测分析系统（Job-SDF、GDELT-Graph）
- 可分析技能需求和行业趋势。
- 但数据粒度单一，LLM生成知识图谱缺乏一致性和可解释性。

第9页｜项目创新点
============================================================
项目创新点

01 可解释的结构化职业决策引擎
- 采用约束规划、多目标评分、路径搜索的结构化方法生成职业路径，结合技能缺口和学习资源映射，输出可解释的路径建议。
- 摆脱黑盒预测，支持“为什么推荐、先补什么、风险与成本多少”的透明决策。

02 多层级职业知识图谱
- 以ESCO/O*NET等标准锚点为基础，组织岗位、技能、资源等层级关系。
- 支撑岗位与技能之间的映射、能力缺口分析和学习资源关联。

03 多源数据融合与趋势预测
- 融合招聘趋势、技能热度、岗位指标、事件影响等多源数据。
- 用于形成趋势预测和行业报告，为职业选择提供长期判断依据。

04 交互式职业决策Agent
- 设计Agent编排层，联合路径Agent、趋势Agent、评估Agent、报告Agent，支持问答交互、模拟what-if、解释生成与证据追踪。
- 用户可实时修改目标，系统动态重排路径和推荐，同时提供可信解释。

项目意义

理论意义
1. 职业决策闭环方法创新
- 将岗位匹配、职业路径规划与行业趋势预测统一到一个可验证、可解释的决策框架，丰富职业推荐与技能需求预测的研究范式。

2. 多尺度标注与图谱建模
- 提出能力单元四层标注方法，为职业知识图谱和能力缺口分析提供方法基础。

3. 混合路径生成与多目标优化
- 将图规划、约束搜索与多目标评分结合，推动职业路径推荐研究从单步预测向整体规划升级。

实践意义
1. 赋能IT从业者
- 提供岗位推荐、技能缺口、学习路径、行业风险的全链路支持，帮助个人清晰规划职业方向。

2. 支撑人才培养与转向
- 帮助高校/机构发现热门岗位能力短板，规划可执行的技能提升路径，降低转向风险。

3. 落地交互系统
- 形成可落地的职业决策工具，具备扩展到课程改革、就业指导的潜力。

整体技术架构图

1. 多源数据层
- 用户数据：简历、GitHub、兴趣偏好、目标岗位。
- 职业市场数据：招聘JD、岗位画像、薪资、城市、经验要求。
- 学习资源数据：课程大纲、教程目录、B站、Coursera、GitHub项目、官方文档。
- 行业趋势数据：招聘时间序列、技术热度、新闻事件、政策、投融资等。

2. 数据处理与标准化层
- 文本清洗与结构化：JobBERT / JobSpanBERT。
- 信息抽取：技能、岗位、学历、经验、薪资等。
- 标准化映射：ESCO粗粒度 + 自建细粒度岗位树。
- 资源清洗与标签化。

3. 核心知识与图谱层
- 职业技能图谱。
- 行业趋势画像库。
- 关键维度包括技能需求变化、岗位热度、薪资趋势、城市分布等。

4. 核心算法层
- 职业匹配：SBERT粗召回 + GraphSAGE精排。
- 学习路径规划：LLM抽取先修关系 + GraphSAGE资源嵌入 + A*路径搜索。
- 行业预测与分析：时间序列模型 + 统计分析 + 事件增强。
- 决策解释与生成：RAG + LLM。
- 路径评分公式：Score(path)=α·Gain − β·Cost − γ·Difficulty。

5. 智能交互与输出层
- 智能交互Agent与多Agent协同。
- 输出岗位推荐、学习路径、行业趋势报告和交互式决策支持。
- 通过模型部署、专家评审、日志校验、用户反馈进行验证与迭代。

第14页｜职业匹配
============================================================
职业匹配

多源数据输入
- 简历/GitHub/项目经历。
- 招聘JD/岗位画像。
- 自建细粒度岗位库。

信息抽取与标准化
- 抽取技能、项目、学历、经验、薪资、城市等信息。
- 构建统一岗位词表 + 技能词表。
- 参考ESCO/O*NET（粗粒度）。

双阶段匹配
- 粗召：Sentence-BERT语义检索，统一岗位词表 + 技能词表。
- 精匹配：特征融合排序模型。
- 输出Top-K候选岗位。

匹配结果输出
- 匹配度。
- 推荐理由。
- 关键技能重合。
- 差异项。

细粒度岗位推荐与分析：AI工程师 → Agent工程师
- 标准库只做大类锚点，自建小类岗位。
- 通过岗位文本聚类 + 专家规则 + LLM归并，形成细粒度岗位树。

多维融合打分机制
- 用户 + 岗位向量相似度。
- 技能迁移路径长度（即转型难度）。
- 岗位薪资、城市偏好、岗位价值加分。
- 最终评分公式：Final_Score = α·Sim(Zu,Zj) − β·Path_Length + γ·Reward。

第15页｜学习路径规划
============================================================
学习路径规划

一、顺序关系抽取
- 数据：课程大纲、教程目录、岗位JD、GitHub项目文档。
- 模型：LLM关系抽取 + 规则过滤 + 人工抽样校验，构建技能DAG。
- 输出：先修技能图。

二、资源语义挂载
- 数据：B站、Coursera、GitHub。
- 处理：标题、摘要、章节目录统一清洗。
- 模型：SBERT做资源—技能语义匹配。
- 根据热度挂载Top-K资源。

三、学习路径生成
- 起点：用户已有技能。
- 终点：目标岗位核心技能。
- 模型：GraphSAGE吸收邻居结构信息。
- 搜索：A* / 最短路径搜索。

四、准确性验证
- 专家评审：检查顺序是否合理。
- 真实转岗案例对照：不要求完全一致，而是看整体趋势是否符合真实职业成长路径。
- 日志与行为数据分析：统计用户在Agent上的操作数据，量化路径执行可行性与决策可操作性。

第16页｜行业预测与分析
============================================================
行业预测与分析

1. 招聘市场主时序
- 招聘JD按周/月聚合。
- 提取岗位数量、薪资中位数、经验门槛、技能频率。
- 按岗位族、城市、公司类型和职位等级构建时序特征。

2. 技术热度辅助线
- Google Trends / 百度指数 / GitHub活跃度。
- 技能关键词与岗位簇热点指数。
- 构建技术景气度与竞品活跃度特征。

3. 外部事件证据层
- GDELT / 公司公告 / 政策新闻 / 融资裁员事件。
- 按时间窗聚合为事件冲击特征。
- 结合时间衰减，形成短期风险/机会信号。
- 服务趋势解释与证据补充，不直接主导预测。

PatchTST多源时序预测
- 多变量序列输入：岗位主时序 + 技术热度 + 事件冲击特征。
- 将长时间序列切分为patch，建模局部趋势与长期依赖。
- 预测：岗位热度指数、技能需求指数、竞争强度代理指标。

证据检索层：图谱 + RAG
- 构建“岗位—技能—事件”关联图谱，组织行业证据与文档片段，支持溯源解释。
- 为Agent提供“为什么推荐 / 为什么预警”的证据支撑。
